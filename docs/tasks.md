Задачи проекта
- принимать текст обращения
- формулировать его краткое содержание
- выделять категорию, важные факты и недостающие данные
- предлагать черновик ответа оператору
- учитывать историю диалога
- анализировать приложенные PDF, DOCX и изображения
- запрашивать разрешенные данные через ограниченные инструменты
- работать как REST API на FastAPI
- возвращать понятные ошибки и записывать безопасные диагностические данные

Ограничения
- не оформляет возврат денег самостоятельно
- не меняет статус заказа без подтверждения и разрешенного инструмента
- не обещает скидку, компенсацию или срок доставки
- не придумывает номер заказа, условия гарантии и другие факты
- не отправляет клиенту ответ без проверки оператором
